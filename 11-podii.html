Події та обробники подій · 11 клас · 13.11 · JavaScript, 12 балів

Подія — це те, що робить користувач: клікає, натискає клавішу, наводить мишку. Обробник — функція, яка запускається, коли подія сталася.

Як це записати

a.el.addEventListener("click", function () {
  a.color = "gold";
  a.draw();
});
ЩоЩо означає
a.elДе слухаємо: коло a на сторінці
addEventListener«Додай слухача події»
"click"Яку подію чекаємо
function () {…}Обробник. Виконається кожного разу, коли клікнуть
ПодіяКоли стається
clickклік мишкою
keydownнатиснули клавішу. Яку — у e.key
mouseoverмишка заїхала на елемент
dblclickподвійний клік

Робота на 12 балів

Завантажити файл podii.html

  1. Відкрий файл у Блокноті (права кнопка → «Відкрити за допомогою») і в браузері (подвійний клік).
  2. Клас Ball і два м'ячі a та b вже є у файлі. Це те, що ви писали минулого разу, плюс метод move(dx, dy).
  3. Пиши код між ПИШИ СВІЙ КОД ТУТ і ДАЛІ НІЧОГО НЕ ЗМІНЮЙ.
  4. Після кожного кроку: у Блокноті Ctrl + S, у браузері F5. Помилку браузер покаже червоним.

Крок 1: клік по м'ячу 3 бали

a.el.addEventListener("click", function () {
  a.color = "gold";
  a.draw();
});

Має вийти: клікнеш по червоному м'ячу — він стане золотим.

Без a.draw() колір у властивості зміниться, а на екрані — ні. Перевір: прибери цей рядок, збережи, F5.

Крок 2: кнопка «Більше» 2 бали

document.getElementById("grow").addEventListener("click", function () {
  a.r = a.r + 10;
  a.draw();
});

Має вийти: кожен клік по кнопці «Більше» збільшує м'яч на 10.

Кнопку знаходимо за її id, як коло. Подія та сама — click.

Крок 3: стрілки на клавіатурі 3 бали

document.addEventListener("keydown", function (e) {
  if (e.key === "ArrowRight") a.move(10, 0);
  if (e.key === "ArrowLeft") a.move(-10, 0);
  if (e.key === "ArrowUp") a.move(0, -10);
  if (e.key === "ArrowDown") a.move(0, 10);
});

Має вийти: стрілки рухають м'яч a.

Клавішу слухає вся сторінка: document. Обробник отримує e — опис події. У e.key назва клавіші.

Вгору — це мінус по y: у SVG y росте донизу.

Крок 4: лічильник і «Скинути» 2 бали

let clicks = 0;
b.el.addEventListener("click", function () {
  clicks = clicks + 1;
  document.getElementById("info").textContent = "Кліків по b: " + clicks;
});

Має вийти: під полем рахуються кліки по зеленому м'ячу.

Сам: напиши обробник для кнопки з id reset. Він повертає м'ячу a x = 150, y = 150, r = 40, колір "tomato" і малює його.

★ Для швидших. Зроби м'яч b «втікачем»: на подію mouseover він стрибає в випадкове місце. Підказка: Math.random() * 520 + 40 дає випадкове число від 40 до 560.
