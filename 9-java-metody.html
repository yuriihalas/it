Методи в Java · 9 клас · 05.11 · ділимо програму на частини

Великий проєкт не пишуть одним шматком. Його ділять на маленькі частини, і кожна робить одну справу. У Java такі частини називаються методами.

Два види методів

У Java все це називається методами. Слова «процедура» (нічого не повертає) і «функція» (повертає результат) — із загальної теорії програмування, вони є в темі уроку й у Python.

Метод void: робить дію, нічого не повертає

static void greet(String name) {
    System.out.println("Привіт, " + name);
}

Метод із результатом: рахує і повертає значення

static int square(int x) {
    return x * x;
}

З чого складається метод

ЧастинаЩо означає
staticПоки що просто пишемо завжди
void / intЩо повертає: нічого або ціле число
squareІм'я: що робить метод
(int x)Параметр: що метод отримує
returnВіддати результат і вийти

Хто вчив Python: def square(x): у Java пишеться static int square(int x) {. Різниця лише в тому, що Java вимагає вказати типи.

Завдання

1. Привітання

Напиши метод greet, щоб програма вивела:

Привіт, Оля!
Привіт, Назар!
public class Main {
    // метод тут

    public static void main(String[] args) {
        greet("Оля");
        greet("Назар");
    }
}
Підказка

static void greet(String name). Рядки склеюємо через +.

2. Квадрат

Напиши метод square. Має вивести:

25
144
public class Main {
    // метод тут

    public static void main(String[] args) {
        System.out.println(square(5));
        System.out.println(square(12));
    }
}
Підказка

Подивись на приклад угорі сторінки.

3. Більше з двох

Напиши метод max, який повертає більше число. Має вивести:

8
10
public class Main {
    // метод тут

    public static void main(String[] args) {
        System.out.println(max(3, 8));
        System.out.println(max(10, 2));
    }
}
Підказка

static int max(int a, int b). Усередині if: якщо a > b, повертаємо a. Інакше b.

4. Парне число

Напиши метод isEven, який повертає true для парного числа. Має вивести:

true
false
public class Main {
    // метод тут

    public static void main(String[] args) {
        System.out.println(isEven(6));
        System.out.println(isEven(7));
    }
}
Підказка

Тип результату — boolean. Перевірка: n % 2 == 0.

Збери разом: чек у кафе

Маленький проєкт із трьох методів. Кожен робить одну справу, а printCheck використовує два інші.

public class Main {
    // 1. total: ціна * кількість
    // 2. discount: якщо сума від 100,
    //    знижка 10%, інакше без знижки
    // 3. printCheck: друкує два рядки чека

    public static void main(String[] args) {
        printCheck("Піца", 60, 3);
        printCheck("Чай", 15, 2);
    }
}

Має вивести:

Піца x 3 = 180 грн
До сплати: 162 грн
Чай x 2 = 30 грн
До сплати: 30 грн
Підказка 
static int total(int price, int count)
static int discount(int sum)
static void printCheck(String item, int price, int count)

Знижка 10%: sum - sum / 10.
