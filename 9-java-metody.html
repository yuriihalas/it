Методи в Java · 9 клас · 05.11 · ділимо програму на частини

Великий проєкт не пишуть одним шматком. Його ділять на маленькі частини, і кожна робить одну справу. У Java такі частини називаються методами.

Спочатку: типи даних

У Java перед іменем завжди стоїть тип. Перед змінною, перед параметром і перед методом.

int age = 14;
String name = "Оля";

static int square(int x) {
    return x * x;
}

Python: age = 14. Тип Python визначає сам.

Java: int age = 14; Тип пишеш ти, і змінити його вже не можна. Java перевіряє типи ще до запуску:

int age = "14";
incompatible types: String cannot
be converted to int

Перші вісім типів базові (примітивні). String і масиви — об'єкти. На уроках найчастіше потрібні int, double, boolean, char, String.

Два види методів

У Java все це називається методами. Слова «процедура» (нічого не повертає) і «функція» (повертає результат) — із загальної теорії програмування, вони є в темі уроку й у Python.

Метод void: робить дію, нічого не повертає

static void greet(String name) {
    System.out.println("Привіт, " + name);
}

Метод із результатом: рахує і повертає значення

static int square(int x) {
    return x * x;
}

З чого складається метод

Хто вчив Python: def square(x): у Java пишеться static int square(int x) {. Різниця лише в тому, що Java вимагає вказати типи.

Тип повернення

Це тип значення, яке метод віддає через return. Він стоїть перед іменем методу.

  • int — метод поверне ціле число.
  • boolean — поверне true або false.
  • void — нічого не поверне, return зі значенням не потрібен.

Тип мусить збігатися. Метод int не може повернути 2.5:

incompatible types: possible lossy
conversion from double to int

Параметри

Це змінні в дужках, через які метод отримує значення. Параметрів може бути скільки завгодно або жодного, тоді дужки порожні.

Кожен параметр має свій тип:

static int add(int a, int b)   // правильно
static int add(int a, b)       // помилка

Значення у виклику йдуть у тому самому порядку: у add(2, 3) буде a = 2, b = 3.

Сигнатура методу

Сигнатура — це ім'я методу і типи його параметрів. За нею Java відрізняє один метод від іншого.

ЗаголовокСигнатура
static int add(int a, int b)add(int, int)
static double add(double a, double b)add(double, double)
static void greet(String name)greet(String)

Тип повернення й імена параметрів до сигнатури не входять.

Тому в одному класі не може бути двох методів з однаковою сигнатурою, навіть якщо типи повернення різні:

static int f(int x)
static double f(int y)
method f(int) is already defined in class Main

Подивись, як іде програма

Які бувають методи

Метод відрізняється двома речами: чи отримує він щось (параметри) і чи віддає щось назад (результат). Тому видів чотири.

Нічого не повертає (void)Повертає результат
Без параметрівstatic void hello()static int dice()
З параметрамиstatic void greet(String name)static int add(int a, int b)
public class Main {
    static void hello() {
        System.out.println("Привіт!");
    }

    static void greet(String name) {
        System.out.println("Привіт, " + name + "!");
    }

    static int dice() {
        return (int) (Math.random() * 6) + 1;
    }

    static int add(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        hello();
        greet("Оля");
        int roll = dice();
        System.out.println("Кубик: " + roll);
        System.out.println(add(2, 3));
    }
}

Програма виведе:

Привіт!
Привіт, Оля!
Кубик: 4
5

Число на кубику щоразу інше: від 1 до 6.

Метод void викликаємо окремим рядком. Результат іншого методу записуємо в змінну або одразу використовуємо.

Тип результату може бути будь-який: int, double, boolean, char, String, int[]. Те, що стоїть після return, має бути саме цього типу.

static і не static

static: метод класу

Працює без об'єкта. Викликаємо через ім'я класу, а всередині свого класу просто за іменем.

Math.max(3, 8)
Cat.info()
square(5)

Не static: метод об'єкта

Працює з конкретним об'єктом і його даними. Спочатку створюємо об'єкт, потім викликаємо через крапку.

word.length()
word.toUpperCase()
a.speak()

Клас — це креслення, об'єкт — конкретна річ за цим кресленням. Клас Cat описує всіх котів, а Мурчик і Барсик — два окремі об'єкти.

class Cat {
    String name;

    Cat(String name) {
        this.name = name;
    }

    void speak() {
        System.out.println(name + ": няв");
    }

    static void info() {
        System.out.println("Усі коти люблять спати");
    }
}

public class Main {
    public static void main(String[] args) {
        Cat a = new Cat("Мурчик");
        Cat b = new Cat("Барсик");
        a.speak();
        b.speak();
        Cat.info();
    }
}

Програма виведе:

Мурчик: няв
Барсик: няв
Усі коти люблять спати
  • speak не static, бо в кожного кота своє ім'я.
  • info static, бо це про всіх котів одразу.
  • Cat(String name) — конструктор: він спрацьовує, коли пишемо new Cat(...). Це єдиний випадок без типу повернення, навіть без void.
  • new створює об'єкт, this.name — ім'я саме цього об'єкта.

Чому main static? Java запускає його першим, коли ще немає жодного об'єкта.

Тому без static буде помилка, якщо викликати метод із main просто за іменем:

non-static method hello() cannot be
referenced from a static context

Важливі деталі

Параметр і аргумент

У static int square(int x) змінна x — параметр. У виклику square(5) число 5 — аргумент. Кількість, порядок і типи мають збігатися.

return завершує метод

static String grade(int points) {
    if (points >= 10) {
        return "Високий";
    }
    return "Ще попрацюй";
}

Код одразу після return ніколи не виконається. Java покаже помилку unreachable statement.

Змінні живуть лише в методі

Змінна, створена в методі, зникає, коли метод закінчується. Тому в різних методах можуть бути змінні з однаковим іменем, і вони не заважають одна одній.

Параметр — це копія

static void addOne(int x) {
    x = x + 1;
}
// у main:
int n = 5;
addOne(n);
System.out.println(n);

Виведе 5: метод змінив копію. А ось елементи масиву метод змінити може, бо отримує посилання на той самий масив.

Однакові імена

static int add(int a, int b)
static int add(int a, int b, int c)
static double add(double a, double b)

Це перевантаження: ім'я однакове, а сигнатури різні. Java вибирає метод за кількістю і типами аргументів.

Як називати методи

Ім'я з малої літери, кожне наступне слово з великої: printCheck, isEven. Найкраще — дієслово, яке каже, що робить метод. Один метод — одна справа.

Де писати код

Пишемо онлайн, нічого встановлювати не треба: відкрити компілятор Java. Зітри там приклад, встав свій код і натисни Run. Клас має називатися Main.

Метод пишемо всередині класу Main, але поза main. Натисни «Копіювати», встав каркас і допиши метод.

Завдання

1. Привітання

Напиши метод greet, щоб програма вивела:

Привіт, Оля!
Привіт, Назар!
public class Main {
    // метод тут

    public static void main(String[] args) {
        greet("Оля");
        greet("Назар");
    }
}
Підказка

static void greet(String name). Рядки склеюємо через +.

2. Квадрат

Напиши метод square. Має вивести:

25
144
public class Main {
    // метод тут

    public static void main(String[] args) {
        System.out.println(square(5));
        System.out.println(square(12));
    }
}
Підказка

Подивись на приклад угорі сторінки.

3. Більше з двох

Напиши метод max, який повертає більше число. Має вивести:

8
10
public class Main {
    // метод тут

    public static void main(String[] args) {
        System.out.println(max(3, 8));
        System.out.println(max(10, 2));
    }
}
Підказка

static int max(int a, int b). Усередині if: якщо a > b, повертаємо a. Інакше b.

4. Парне число

Напиши метод isEven, який повертає true для парного числа. Має вивести:

true
false
public class Main {
    // метод тут

    public static void main(String[] args) {
        System.out.println(isEven(6));
        System.out.println(isEven(7));
    }
}
Підказка

Тип результату — boolean. Перевірка: n % 2 == 0.

Збери разом: чек у кафе

Маленький проєкт із трьох методів. Кожен робить одну справу, а printCheck використовує два інші.

public class Main {
    // 1. total: ціна * кількість
    // 2. discount: якщо сума від 100,
    //    знижка 10%, інакше без знижки
    // 3. printCheck: друкує два рядки чека

    public static void main(String[] args) {
        printCheck("Піца", 60, 3);
        printCheck("Чай", 15, 2);
    }
}

Має вивести:

Піца x 3 = 180 грн
До сплати: 162 грн
Чай x 2 = 30 грн
До сплати: 30 грн
Підказка 
static int total(int price, int count)
static int discount(int sum)
static void printCheck(String item, int price, int count)

Знижка 10%: sum - sum / 10.

Перевір себе

Впиши відповідь і натисни «Перевірити» або Enter. Перевірити можна лише один раз.

Правильно: 0 з 10

Остання задача: твій метод

Кожен вигадує і пише свій метод. Можна шукати в інтернеті, але ти маєш пояснити кожен рядок свого коду.

Умови

  1. Своя ідея, не така, як у сусіда.
  2. Метод отримує хоча б один параметр і повертає результат.
  3. У main виклич його двічі з різними значеннями.
  4. Покажи запуск учителю і поясни, що робить кожен рядок.
public class Main {
    // мій метод тут

    public static void main(String[] args) {
        // виклич його двічі
    }
}
