Повторення розділу: 8 програм · 8-А · 24.11 · Python

  1. Відкрий Thonny: Файл → Новий.
  2. Набери програму з картинки (номери рядків зліва набирати не треба).
  3. Запусти зеленою кнопкою ▶ і відповідай на питання під програмою.
  4. Де написано «Зміни» чи «Заміни» — зміни код, запусти ще раз і тоді відповідай.

1 Арифметика

/ — звичайне ділення, // — ціла частина, % — остача, ** — степінь.

2 Розгалуження if / elif / else

Python перевіряє умови згори вниз і виконує першу правдиву. Решту пропускає.

3 Логічні оператори and / or

and — правда, коли правдиві обидві умови. or — коли правдива хоча б одна.

4 Цикл for і range

range(1, 11, 3) — від 1, до 11 (саме 11 не входить), крок 3.

5 Цикл while

while повторює, поки умова правдива. Тут — поки гроші більші за 0.

6 Умова всередині циклу

n % 3 == 0 — число ділиться на 3 без остачі. Цикл перебирає числа, if відбирає потрібні.

7 Вкладені цикли

Внутрішній цикл повністю проходить для кожного кроку зовнішнього. end=" " — не переходити на новий рядок.

8 Знайди й виправ помилки

У цій програмі три помилки: синтаксична, логічна і помилка виконання. Набери її саме так, як тут.

Сам: у програмі 8 зроби так, щоб для кількості 0 вона писала Немає чисел і не падала. Підказка: if n > 0: перед рядком з print.

Твій проєкт

Встиг усі 8 програм? Відкрий свій proekt.py і перевір його на чотирьох видах даних:

  • звичайні числа;
  • межові (найменше і найбільше можливе);
  • 0 або від'ємне число;
  • букви замість числа.

Знайшов, де програма падає чи рахує не те, — виправ і запусти ще раз.
