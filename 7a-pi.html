Число Пі в кольорах · 7-А · Практична робота № 2 · Python, turtle

Пі — це число, яке показує, у скільки разів коло довше за свою ширину (діаметр): приблизно в 3,14 раза. Його цифри йдуть без кінця і ніколи не повторюються по колу. Сьогодні 50 перших цифр Пі стануть чотирма картинами.

3,141592653 5897932384 6264338327 9502884197 1693993751

Thonny → File → New. Збережи файл як pi.py (тільки не turtle.py!). Переписуй крок за кроком. Після кожного кроку тисни F5: програма вже працює і малює.

Як цифра стає картинкою

РядокЩо робить
pi = "3141..."Усі 50 цифр в одному рядку тексту. Звіряй по 10 цифр із чорною смужкою вгорі.
colors = [...]Список із 10 кольорів. Кожна цифра має свій колір: 0 — білий, 1 — червоний, 2 — помаранчевий і так далі.
pi[i]Цифра під номером i. Рахуємо з нуля: pi[0] — це 3, pi[1] — це 1.
int(pi[i])Перетворює текст "4" на число 4, з яким можна рахувати.
colors[d]Колір для цифри d.
i % 10Місце в ряду: 0, 1, 2 … 9, а потім знову 0. Залишок від ділення на 10.
i // 10Номер ряду: перші 10 кружечків — ряд 0, наступні 10 — ряд 1. Ділення без остачі.
t.dot(52, колір)Кружечок розміром 52.
t.write(d, ...)Пише цифру на екрані.
d * 36Напрямок прогулянки: 10 цифр — 10 напрямків, бо 360 ÷ 10 = 36.
pi.count("9")Рахує, скільки разів у рядку трапляється цифра 9.
screen.onkey(carpet, "1")Клавіша 1 малює килимок. Спершу клацни мишкою по вікну з малюнком.

Крок 1. Килимок із цифр

import turtle

screen = turtle.Screen()
screen.setup(900, 650)
screen.bgcolor("black")
screen.tracer(0)

t = turtle.Turtle()
t.hideturtle()
t.penup()

pi = "31415926535897932384626433832795028841971693993751"
colors = ["white", "red", "orange", "yellow", "lime",
          "cyan", "skyblue", "violet", "pink", "tan"]

def carpet():
    t.clear()
    for i in range(50):
        d = int(pi[i])
        x = -270 + i % 10 * 60
        y = 120 - i // 10 * 60
        t.goto(x, y)
        t.dot(52, colors[d])
        t.goto(x, y - 12)
        t.color("black")
        t.write(d, align="center", font=("Arial", 16, "bold"))
    screen.update()

carpet()
screen.onkey(carpet, "1")
screen.listen()
turtle.done()

Перепиши все й тисни F5. Має з'явитися килимок. Якщо помилка — таблиця «Якщо не працює» внизу.

Зміни число: 52 → 30 (менші кружечки), потім 60 → 55. Поверни як було.

Крок 2. Квітка Пі

def flower():
    t.clear()
    for i in range(50):
        d = int(pi[i])
        t.goto(0, 0)
        t.setheading(i * 137)
        t.forward(10 + i * 5)
        t.dot(8 + d * 4, colors[d])
    screen.update()

Встав функцію над рядком carpet() внизу. Під screen.onkey(carpet, "1") допиши: screen.onkey(flower, "2"). F5, клацни по вікну, натисни 2.

Зміни число: 137 → 90, потім 36, потім 100. Що змінюється? Поверни 137.

Крок 3. Прогулянка Пі

def walk():
    t.clear()
    t.goto(120, -180)
    t.width(4)
    t.pendown()
    for i in range(50):
        d = int(pi[i])
        t.color(colors[d])
        t.setheading(d * 36)
        t.forward(60)
        t.dot(12)
    t.penup()
    screen.update()

Знову над carpet(). Під клавішею 2 допиши: screen.onkey(walk, "3"). F5, натисни 3.

Зміни число: 60 → 30 (короткі кроки), t.width(4) → t.width(8).

Крок 4. Скільки яких цифр

def chart():
    t.clear()
    t.width(40)
    for d in range(10):
        n = pi.count(str(d))
        x = -270 + d * 60
        t.goto(x, -200)
        t.color(colors[d])
        t.pendown()
        t.goto(x, -200 + n * 40)
        t.penup()
        t.goto(x, -170 + n * 40)
        t.write(n, align="center", font=("Arial", 16, "bold"))
        t.goto(x, -240)
        t.write(d, align="center", font=("Arial", 16, "bold"))
    screen.update()

Над carpet(). Під клавішею 3 допиши: screen.onkey(chart, "4"). F5, натисни 4. Тепер працюють клавіші 1, 2, 3, 4.

Зміни число: t.width(40) → t.width(20). Яка цифра трапляється найчастіше? Відповідь знадобиться в тесті.

Якщо не працює

Що бачишЩо робити
IndexError: string index out of rangeУ рядку pi менше 50 цифр. Звір по 10 із чорною смужкою вгорі.
IndexError: list index out of rangeУ списку colors не 10 кольорів. Найчастіше забута кома між словами.
NameError: name '...' is not definedПомилка в назві. colors, carpet, flower пиши однаково скрізь.
IndentationError, SyntaxErrorЗабута двокрапка після def або for, чи немає відступу 4 пробіли.
Клавіші нічого не роблятьКлацни мишкою по вікну з малюнком. Перевір рядки screen.onkey і screen.listen().
Кружечки без кольору, помилка bad colorПомилка в назві кольору: "skyblue", "violet" пишуться разом і маленькими літерами.

Для тих, хто вже все зробив ★

  1. Додай у кінець рядка pi ще 50 цифр Пі: 05820974944592307816406286208998628034825342117067. У квітці й прогулянці заміни range(50) на range(100), а в квітці ще i * 5 на i * 3. У діаграмі n * 40 заміни на n * 20, щоб стовпчики влізли.
  2. Свої кольори: заміни будь-які 3 кольори в списку colors.
  3. Клавіша 5: квітка з кутом 90. Скопіюй flower, назви flower2 і зміни число.
  4. Замість Пі візьми інше число, наприклад "27182818284590452353602874713526624977572470936999": це перші 50 цифр числа e. Чим відрізняється діаграма?

Тест: 5 питань

Відповідай числом. Підказки є в коді та на картинках.

Правильно: 0 з 5

Практична робота № 2: що показати вчителю

  • Програма запускається без помилок, і клавіші 1, 2, 3, 4 малюють чотири картини.
  • Хоча б одне число змінене так, як у рядку «Зміни число».
  • Тест: усі 5 відповідей.
