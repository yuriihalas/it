Набір даних — це багато однотипних записів. Сьогодні аналізуємо справжні дані: який відсоток людей в Україні користується інтернетом.

Працюємо в Thonny. Перепиши код точно як на сторінці, частинами, і запускай після кожного кроку. Назви файл dani.py. Не називай його statistics.py, інакше програма не працюватиме.

Крок 1: дані й підрахунки 3 бали

import statistics

years = [2015, 2016, 2017, 2018, 2019, 2020, 2021, 2022, 2023, 2024]
ukraine = [48.9, 53.0, 58.9, 62.6, 70.1, 75.0, 79.2, 80.5, 81.6, 82.5]

print("Записів:", len(ukraine))
print("Середнє:", round(statistics.mean(ukraine), 1))
print("Медіана:", round(statistics.median(ukraine), 1))
print("Мінімум:", min(ukraine))
print("Максимум:", max(ukraine))
print("Розмах:", round(max(ukraine) - min(ukraine), 1))

Має вивести:

Записів: 10
Середнє: 69.2
Медіана: 72.5
Мінімум: 48.9
Максимум: 82.5
Розмах: 33.6
КодЩо робить

years, ukraineДва списки: роки і значення. Це наш набір даних
len(ukraine)Скільки значень у списку
statistics.meanСереднє значення
statistics.medianМедіана: значення посередині впорядкованого списку
round(число, 1)Округлює до десятих
min, maxНайменше і найбільше. Розмах — це їхня різниця

Крок 3: шукаємо в даних 3 бали

Допиши далі:

print()
count = 0
for value in ukraine:
    if value > 70:
        count = count + 1
print("Років понад 70%:", count)

for i in range(len(years)):
    if ukraine[i] > 50:
        print("Вперше понад 50%:", years[i])
        break

Має вивести:

Років понад 70%: 6
Вперше понад 50%: 2016

Перший цикл рахує, скільки значень більші за 70. Другий шукає перше значення понад 50, а break одразу зупиняє цикл.
