Клас, властивості, конструктор, методи · 11 клас · JavaScript

Клас — це креслення. Об'єкт — річ, зроблена за цим кресленням. Одне креслення, скільки завгодно речей.

Навіщо клас

Без класу

let x1 = 100, y1 = 150, r1 = 40;
let x2 = 300, y2 = 150, r2 = 60;
let x3 = 500, y3 = 150, r3 = 20;

Кожен новий м'яч — це ще три змінні. Легко заплутатися, чий x.

З класом

const a = new Ball(100, 150, 40);
const b = new Ball(300, 150, 60);
const c = new Ball(500, 150, 20);

Кожен м'яч сам зберігає свої дані: a.x, b.x, c.x.

З чого складається клас

class Ball {
  constructor(x, y, r) {
    this.x = x;
    this.y = y;
    this.r = r;
  }

  move(dx) {
    this.x = this.x + dx;
  }
}

const a = new Ball(100, 150, 40);
a.move(20);
console.log(a.x);   // 120
ЩоЩо означає
class BallОголошуємо клас. Назву пишуть з великої літери.
constructorКонструктор. Запускається сам, коли пишемо new. Заповнює об'єкт даними.
this«Цей об'єкт». Для a це a, для b це b.
this.xВластивість. Змінна, що належить об'єкту.
move(dx)Метод. Функція всередині класу. Слова function тут немає.
new Ball(...)Створює новий об'єкт. Числа йдуть у параметри конструктора по порядку.
a.move(20)Виклик методу через крапку.

Крок 1. Клас і два м'ячі 3 бали

Перепиши код руками, не копіюй: так ти запам'ятаєш, де що стоїть.

class Ball {
  constructor(id, x, y, r, color) {
    this.el = document.getElementById(id);
    this.x = x;
    this.y = y;
    this.r = r;
    this.color = color;
  }

  draw() {
    this.el.setAttribute("cx", this.x);
    this.el.setAttribute("cy", this.y);
    this.el.setAttribute("r", this.r);
    this.el.setAttribute("fill", this.color);
  }
}

const a = new Ball("a", 100, 150, 40, "tomato");
const b = new Ball("b", 300, 150, 60, "teal");
a.draw();
b.draw();

Має вийти: два кола на сірому полі.

<circle> ви вже знаєте зі SVG: cx, cy, r, fill. Тут ці атрибути ставить метод draw.

this.el — властивість, де об'єкт тримає своє коло зі сторінки. У файлі вже є кола з id a, b, c.

Крок 2. Метод move 2 бали

Додай цей метод усередину класу, після draw:

  move(dx, dy) {
    this.x = this.x + dx;
    this.y = this.y + dy;
    this.draw();
  }

А цю функцію допиши в самому кінці, поза класом:

function step() {
  a.move(20, 0);
  b.move(0, -10);
}

Має вийти: кнопка «Крок» рухає a праворуч, а b вгору.

Крок 3. Сам: третій м'яч і метод grow 2 бали

Тут коду немає, напиши сам за зразком кроків 1 і 2.

  1. Створи третій об'єкт c зі своїми числами й кольором. Перший аргумент — "c". Намалюй його.
  2. Додай у клас метод grow(d): він збільшує this.r на d і викликає this.draw().

Має вийти: кнопка «Більше» збільшує третій м'яч.
