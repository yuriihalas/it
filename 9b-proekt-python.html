Проєкт — це програма за планом

Минулого разу ми вчили функції. Сьогодні складаємо з них цілі невеликі програми — проєкти. Великий проєкт ніхто не пише одразу: спершу план, потім маленькі функції, кожна з яких робить одну справу, і перевірка кожної.

План проєкту в 5 кроках

КрокЩо робимоПриклад: гра «Вгадай число»
1. ІдеяЩо робить програма і для кого — одне реченняКомп'ютер загадує число від 1 до 100, гравець вгадує з підказками
2. Вхід і вихідЩо вводить користувач, що він бачитьВхід: числа гравця. Вихід: «Більше» / «Менше» / «Вгадав!» і кількість спроб
3. ФункціїРозбиваємо на частини — кожна функція робить одну справуmake_secret(), hint(guess, secret) і основна частина з циклом while
4. Перша версіяНайпростіша програма, яка вже працює. Потім покращуємоСпершу без лічильника спроб, потім додаємо його і рекорд
5. ПеревіркаТести: вхід → очікуваний результатhint(30, 50) → «Більше», hint(50, 50) → «Вгадав!»

# 2) а нижче — виклики з даними з питань:
print(hint(30, 50))

Шість міні-проєктів

Кожна функція — це головна частина маленького проєкту. Скопіюй функцію, викликай її з даними з питань і відповідай, що вона повертає насправді. У завданнях 5 і 6 є прихована помилка, як у справжніх програмах: на одних даних усе правильно, на інших — ні.

Завдання 1. Гра «Вгадай число»

Комп'ютер загадав число secret, гравець називає guess. Функція підказує: більше, менше чи вгадав.

def hint(guess, secret):
    if guess < secret:
        return "Більше"
    elif guess > secret:
        return "Менше"
    return "Вгадав!"

Завдання 2. Надійність пароля

Пароль отримує бал за кожне: довжина від 8 символів, є цифра, є велика літера. Максимум 3 бали.

def score(p):
    s = 0
    if len(p) >= 8:
        s = s + 1
    for c in p:
        if c.isdigit():
            s = s + 1
            break
    for c in p:
        if c.isupper():
            s = s + 1
            break
    return s

Завдання 3. Камінь, ножиці, папір

Камінь б'є ножиці, ножиці б'ють папір, папір б'є камінь. Функція каже, хто переміг.

def winner(a, b):
    if a == b:
        return "нічия"
    if (a == "камінь" and b == "ножиці"
            or a == "ножиці" and b == "папір"
            or a == "папір" and b == "камінь"):
        return "перший"
    return "другий"

Завдання 4. Шифр Цезаря

Кожну маленьку латинську літеру зсуваємо на k далі по алфавіту; після z знову йде a. Так шифрував листи Юлій Цезар.

def shift(s, k):
    r = ""
    for c in s:
        r = r + chr(ord("a") + (ord(c) - ord("a") + k) % 26)
    return r

Завдання 5. Знижка в магазині

Від 500 грн — знижка 5 %, від 1000 грн — знижка 10 %. Функція повертає ціну зі знижкою. У функції є прихована помилка — знайди її тестами.

def price(total):
    if total >= 1000:
        return total * 0.9
    elif total > 500:
        return total * 0.95
    return total

Завдання 6. Високосний рік

Рік високосний, якщо ділиться на 4. Але роки, що діляться на 100, — не високосні, крім тих, що діляться на 400 (2000 — високосний, 1900 — ні). Тут теж прихована помилка.

def is_leap(year):
    return year % 4 == 0

  3. Збери гру «Вгадай число» повністю: import random, random.randint(1, 100), цикл while, input і функція hint. Додай лічильник спроб.
