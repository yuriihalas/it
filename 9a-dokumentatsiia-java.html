Коментарі в коді

Пояснення прямо в програмі. Java їх пропускає. Однорядковий: //. Документаційний (Javadoc): /** ... */.

Три правила гарного коментаря

ПравилоПоганоДобре
1. Пояснюй «навіщо», а не «що». Що робить рядок, і так видно з коду.// додаємо 1 до tries// рахуємо спроби, щоб похвалити за швидку гру
2. Коментар має бути правдою. Змінив код — зміни коментар.// знижка 5 % над total * 0.9// знижка 10 %
3. Коротко, грамотно, окремим рядком над кодом// тут шось робимо з r// після z знову йде a

І ще: найкращий коментар — зрозуміла назва. shift(text, k) не треба пояснювати, а f(a, b) — треба.

Зразок: так виглядає задокументований код

/**
 * Шифр Цезаря: зсуває кожну малу
 * латинську літеру на k позицій.
 *
 * @param text слово з малих латинських літер
 * @param k на скільки позицій зсунути
 * @return зашифроване слово
 */
static String shift(String text, int k) {
    String result = "";
    for (char c : text.toCharArray()) {
        // номер літери від 0 до 25;
        // % 26: після z знову йде a
        int n = (c - 'a' + k) % 26;
        result = result + (char) ('a' + n);
    }
    return result;
}

Javadoc — коментар /** ... */ над методом. Теги: @param — що означає параметр, @return — що метод повертає. З них програма javadoc робить сторінку документації, як на docs.oracle.com.

Коментар усередині пояснює навіщо % 26 — це не видно з коду одразу.

Завдання 1. Знайди погані коментарі

Метод рахує ціну зі знижкою. У коді 5 коментарів, вони пронумеровані в таблиці справа. Серед них є:

  • неправильний — пише не те, що насправді робить код під ним;
  • зайвий — лише повторює те, що й так видно в рядку під ним.

Знайди обидва. Номери впишеш у тест, питання 1 і 2.

// ціна зі знижкою для кошика покупця
static double price(double total) {
    // якщо total >= 1000
    if (total >= 1000) {
        // знижка 5 %
        return total * 0.9;
    }
    // знижка 5 %
    if (total >= 500) {
        return total * 0.95;
    }
    // менше 500 грн — без знижки
    return total;
}

Підказка: * 0.95 — знижка 5 %, * 0.9 — знижка 10 %. Перевір: запусти price(1200) і price(600).

Завдання 2. Зроби код зрозумілим

Це той самий шифр Цезаря з 12.11, але написаний «для себе». Перепиши його в онлайн-компілятор Java і:

static String f(String a, int b) {
    String r = "";
    for (char c : a.toCharArray()) {
        r = r + (char) ('a' + (c - 'a' + b) % 26);
    }
    return r;
}
  1. Дай зрозумілі назви: f → shift, a → text, b → k, r → result.
  2. Додай Javadoc: що робить, що означають параметри, що повертає.
  3. Додай один коментар про % 26.
  4. Запусти: shift("abc", 1) має дати bcd. Код після змін працює так само!
    Як у 12.11: метод — над main, а в main — System.out.println(shift("abc", 1));

★ Напиши Javadoc і для методу price: що означає total і що метод повертає.

Завдання 2Б. Розшифрування

Навіщо. Шифр потрібен, щоб повідомлення прочитав тільки той, хто знає ключ. Друг зашифрував слово ключем 3 і надіслав тобі khoor. Чужий бачить безглузді букви. А ти знаєш ключ: зсуваєш кожну букву на 3 назад — і читаєш hello. Шифрування без розшифрування нікому не потрібне.

Як це працює. В алфавіті 26 букв, після z знову a — як на циферблаті. Зсунути на 3 назад — те саме, що на 23 вперед (3 + 23 = 26, повне коло). Тому новий метод просто викликає shift з ключем 26 - k.

/**
 * Розшифровує текст, зашифрований шифром Цезаря.
 *
 * @param text зашифрований текст (малі латинські літери)
 * @param k ключ: на скільки зсували (від 0 до 25)
 * @return початковий текст
 */
static String unshift(String text, int k) {
    // назад на k — те саме, що вперед на 26 - k
    return shift(text, 26 - k);
}
  1. Додай метод unshift під shift (обидва — над main).
  2. Розшифруй повідомлення друга. У main: System.out.println(unshift("khoor", 3)); — має вийти hello.
  3. Перевір, що обидва методи правильні: зашифруй слово, розшифруй тим самим ключем — має повернутися те саме слово.
String word = "java";
String secret = shift(word, 7);
String back = unshift(secret, 7);
System.out.println(secret + " -> " + back);
System.out.println(back.equals(word));
qhch -> java
true

true — розшифрували і отримали те саме слово, отже методи працюють. Перевір так ще "xyz" з ключем 3 (букви переходять через z) і своє ім'я латиницею.

★ Ключ невідомий? Спробуй усі 25 ключів — і знайди рядок, де вийшло справжнє англійське слово. Розшифруй dwwdfn:

for (int k = 1; k < 26; k++) {
    System.out.println(k + " " + unshift("dwwdfn", k));
}

Так шифр Цезаря і зламують: ключів лише 25, комп'ютер перебирає їх за мить. Тому для справжніх секретів використовують складніші шифри.

Частина 2. Оформлення коду

Коментарі — половина справи. Друга половина — оформлення: однакові правила, як писати код, для всіх, хто його пише. Тоді будь-хто відкриває чужий код і читає його легко, як книжку.

У Java ці правила звуться Java Code Conventions. Великі компанії пишуть свої, наприклад Google Java Style. На роботі код, оформлений не за правилами, просто не приймуть.

ЩоПравилоПриклад
Змінні й методиcamelCase: з малої літери, кожне нове слово — з великоїtriesCount, getBalance()

Пробілинавколо = + < >=, після коми, перед {sum = sum + marks[i];

Завдання 4. Оформ код за правилами

Програма рахує середню оцінку. Вона працює, але читати її важко. Перепиши її в онлайн-компілятор Java за правилами з таблиці.

public class Main{
public static void main(String[] args){
int[] M={10,12,9,7};int S=0;
for(int i=0;i<M.length;i++){S=S+M[i];}
double Avg=S/4.0;
if(Avg>=10){System.out.println("Високий");}else{System.out.println("Не високий");}
System.out.println(Avg);}}

Вивід — до і після змін має бути однаковим:

Не високий
9.5
  1. Одна команда — один рядок, відступи по 4 пробіли, } — на окремому рядку.
  2. Назви: M → marks, S → sum, Avg → average.
  3. Пробіли навколо =, +, <, >= і після ком у масиві.
  4. Замість 4.0 — кількість оцінок: sum / (double) marks.length. Тепер код працює для будь-якої кількості оцінок.
  5. Число 10 → константа над main: static final int HIGH = 10;
  6. Додай один коментар «навіщо» — над рядком із діленням.

★ Зміни оцінки на {12, 11, 10}. Програма має сама порахувати правильно, без інших змін. Яку частину коду ти вже не мусив чіпати і чому?
