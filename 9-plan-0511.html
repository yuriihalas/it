Про 9-Б

9-Б вчив переважно Python, тому Java для нього нова. Каркас із public class Main не пояснюй докладно: кажи, що це обгортка, яка є в кожній програмі. Важливо лише, де стоїть метод. На сторінці є кнопка «Копіювати», тож каркас діти не набирають. Клас Cat покажи лише запуском, без конструктора. Головне, щоб побачили різницю Math.max(3, 8) і word.length(). Якщо важко, досить завдань 1–2, тесту і простого свого методу.

Пишемо онлайн у programiz, посилання є на сторінці учнів. Встановлювати нічого не треба: зітерти приклад, вставити каркас, натиснути Run. Клас має називатися Main.

Що сказати про терміни

  • Тип повернення — тип значення, яке віддає return; void, якщо нічого.
  • Сигнатура — ім'я методу і типи параметрів, наприклад add(int, int). Тип повернення й імена параметрів не входять. Весь рядок static int add(int a, int b) — це заголовок, а не сигнатура.
  • Тип доступу — це теж модифікатори: public, protected, private і default, коли нічого не написано. Слово default перед методом класу дає помилку. Стосується методів, змінних класу й класів, тому повністю пояснювати варто на уроці про класи. abstract, synchronized, native лише для довідки.
  • Три крапки (int... nums, англійською varargs): будь-яка кількість значень. Усередині це масив.
  • Параметр — змінна в дужках у методі. Аргумент — значення, яке передаєш під час виклику.
  • У Java є лише методи. «Процедура» і «функція» — загальні терміни з теми уроку: процедура відповідає методу з void, функція — методу, що повертає значення. У коді й на сторінці кажемо «метод».
  • static — метод класу, працює без об'єкта. Не static — метод об'єкта, викликається через об'єкт і працює з його даними.
  • Якщо спитають про винятки з правила «тип завжди попереду»: конструктор не має типу повернення, а var x = 5; (Java 10+) не пише тип, але він усе одно є і не змінюється.
  • Чому main static: Java запускає його, коли ще немає жодного об'єкта.
  • Змінні методу живуть лише поки він працює. Тому x у показі зникає.

Остання задача: як перевіряти

Шукати в інтернеті можна. Тому перевіряй не лише запуск: покажи на рядок і спитай, що він робить, і попроси змінити одне значення.

Якщо хочеш оцінку, можна так: метод працює — 4 бали, має параметр і результат — 2, викликаний двічі — 2, учень пояснив кожен рядок — 4. Разом 12. В КТП цей урок без практичної, тож оцінка за бажанням.

Домашнє

За КТП: вивчити, що таке функція, параметр і значення, яке функція повертає. Плюс на сторінці є 12 питань рівня Junior і 10 рівня Middle з відповідями, які відкриваються кліком. Питання Middle вимагають класів і нащадків, яких діти ще не вчили, тому питай їх лише в тих, кому цікаво. Наступного уроку можна почати з 2–3 питань Junior.
