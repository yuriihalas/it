Де писати код

Відкрий онлайн-компілятор Java. Зітри там приклад, встав каркас і натисни Run. Клас має називатися Main.

Метод пишемо всередині класу Main, але поза main: на місці рядка «// метод тут».

Як написати будь-який метод: 6 кроків

КрокПитання до себеЩо отримуємо
1. Ім'яЩо робить метод?Ім'я з малої літери, дієслово або зрозуміле слово
2. ПараметриЩо він отримує? Якого типу?Дужки: (int x) або порожні ()
3. Тип поверненняЩо він віддає назад?int, boolean, String… Якщо нічого, то void
4. ЗаголовокЯк усе це записати?static, тип повернення, ім'я, параметри, {
5. ТілоЯкі дії потрібні?Код усередині { }. Якщо тип не void, потрібен return
6. ВикликЧи працює?Запусти і порівняй із прикладом виводу

Розв'язуємо разом

Завдання: метод triple отримує ціле число і повертає його, помножене на 3.

  1. Ім'я: triple, воно вже дане.
  2. Параметри: отримує ціле число, отже (int x).
  3. Тип повернення: повертає ціле число, отже int.
  4. Заголовок: збираємо все разом:
static int triple(int x) {
}
  1. Тіло: тип не void, тому потрібен return:
static int triple(int x) {
    return x * 3;
}
  1. Виклик: ставимо метод у клас і викликаємо з main:
public class Main {
    static int triple(int x) {
        return x * 3;
    }

    public static void main(String[] args) {
        System.out.println(triple(4));
        System.out.println(triple(10));
    }
}
12
30

Скопіюй, запусти і зміни множник на 5, щоб побачити, як працює метод.

Завдання

Для кожного завдання пройди ті самі 6 кроків. Спочатку подумай сам, потім за потреби відкрий підказки. Готове покажи вчителю запуском.

1. Привітання

Метод greet отримує ім'я і друкує привітання. Повертати нічого не треба.

public class Main {
    // метод тут

    public static void main(String[] args) {
        greet("Оля");
        greet("Назар");
    }
}
Привіт, Оля!
Привіт, Назар!
Підказка 1: параметри і тип

Отримує текст, отже параметр String name. Нічого не повертає, отже void.

Підказка 2: тіло

Усередині один рядок System.out.println. Рядки склеюємо через +: "Привіт, " + name + "!".

2. Квадрат

Метод square отримує ціле число і повертає його квадрат.

public class Main {
    // метод тут

    public static void main(String[] args) {
        System.out.println(square(5));
        System.out.println(square(12));
    }
}
25
144
Підказка 1: параметри і тип

Отримує int, повертає int. Це той самий заголовок, що в triple, лише з іншим іменем.

Підказка 2: тіло

Квадрат — це число, помножене саме на себе.

3. Більше з двох

Метод max отримує два цілі числа і повертає більше.

public class Main {
    // метод тут

    public static void main(String[] args) {
        System.out.println(max(3, 8));
        System.out.println(max(10, 2));
    }
}
8
10
Підказка 1: параметри і тип

Два параметри, у кожного свій тип: (int a, int b). Повертає int.

Підказка 2: тіло

Якщо a > b, робимо return a;. Після if пишемо return b;, бо інакше буде missing return statement.

4. Парне число

Метод isEven отримує ціле число. Для парного повертає true, для непарного false.

public class Main {
    // метод тут

    public static void main(String[] args) {
        System.out.println(isEven(6));
        System.out.println(isEven(7));
    }
}
true
false
Підказка 1: параметри і тип

Отримує int. Повертає так чи ні, отже boolean.

Підказка 2: тіло

Парне число ділиться на 2 без остачі: n % 2 == 0. Цей вираз уже дає true або false, тож його можна поставити одразу після return.

Збери разом: чек у кафе

Маленький проєкт із трьох методів. Пиши їх по одному, по порядку: наступний використовує попередні.

  1. total отримує ціну і кількість, повертає їхній добуток.
  2. discount отримує суму. Якщо вона від 100, повертає суму зі знижкою 10%, інакше без знижки.
  3. printCheck отримує назву, ціну і кількість, друкує два рядки чека.
public class Main {
    // метод total
    // метод discount
    // метод printCheck

    public static void main(String[] args) {
        printCheck("Піца", 60, 3);
        printCheck("Чай", 15, 2);
    }
}

Має вивести:

Піца x 3 = 180 грн
До сплати: 162 грн
Чай x 2 = 30 грн
До сплати: 30 грн
Підказка 1: заголовки 
static int total(int price, int count)
static int discount(int sum)
static void printCheck(String item, int price, int count)
Підказка 2: тіло

Знижка 10%: sum - sum / 10.

У printCheck спочатку порахуй: int sum = total(price, count);. Потім друкуй, а для другого рядка виклич discount(sum).

Остання задача: твій метод

Кожен вигадує і пише свій метод. Можна шукати в інтернеті, але ти маєш пояснити кожен рядок свого коду.

Умови

  1. Своя ідея, не така, як у сусіда.
  2. Метод отримує хоча б один параметр і повертає результат.
  3. У main виклич його двічі з різними значеннями.
  4. Покажи запуск учителю і поясни, що робить кожен рядок.
public class Main {
    // мій метод тут

    public static void main(String[] args) {
        // виклич його двічі
    }
}
