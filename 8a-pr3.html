Практична робота № 3 · вкладені цикли · 8-А · 05.11

Розминка: що виведе?

Подумай, потім впиши відповідь. Перевірити можна лише один раз.

Теорія: усе, що потрібно для роботи

input(): введення

text = input()

Програма зупиняється і чекає. Введи значення й натисни Enter. Значення запишеться в змінну.

input() завжди дає текст, навіть якщо ввести число.

int(): робимо з тексту число

rows = int(input())

Читаємо зсередини: input() дає текст "3", а int() робить із нього число 3.

Навіщо: range і арифметика працюють лише з числами. Без int() буде помилка:

n = input()
for i in range(n):
TypeError: 'str' object cannot be
interpreted as an integer

print(): виведення

print("Ряд", 1, "місце", 2)
Ряд 1 місце 2

Значення пишемо через кому, а Python сам ставить між ними пробіл. Текст у лапках, змінні без лапок.

print(f"рядків {rows}, стовпців {cols}")
рядків 2, стовпців 4

Літера f перед лапками означає: підстав значення змінних у фігурних дужках.

end і порожній print()

Звичайний print після друку переходить на новий рядок.

print("*", end=" ")
print("*", end=" ")
print()
* *

end=" " — замість нового рядка поставити пробіл, тому зірочки стоять поруч.

print() — просто перейти на новий рядок.

range(): які числа дає цикл

ЗаписЧисла
range(5)0, 1, 2, 3, 4
range(1, 5)1, 2, 3, 4
range(3, 0, -1)3, 2, 1
range(i)стільки кроків, скільки в i

Останнє число не входить. Щоб нумерувати з 1 до 4, пишемо range(1, 5).

Вкладений цикл

for i in range(3):
    for j in range(4):
        print("*", end=" ")
    print()

Зовнішній цикл — рядки, внутрішній — стовпці.

Поки i робить 1 крок, j проходить усі свої. print() стоїть під внутрішнім for, тому спрацьовує після кожного рядка. Відступ — 4 пробіли, після for і if двокрапка.

if, else і остача %

if (i + j) % 2 == 0:
    print("#", end=" ")
else:
    print(".", end=" ")

% — остача від ділення: 8 % 2 дає 0, 7 % 2 дає 1. Якщо остача 0, число парне. == порівнює, а один знак = записує в змінну.

Чому i + j дає шахівницю

Ось суми i + j у кожній клітинці:

0 1 2 3
1 2 3 4
2 3 4 5

Парні й непарні числа чергуються і в рядку, і в стовпці. Для парних друкуємо один символ, для непарних інший.
