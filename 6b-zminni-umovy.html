Сьогодні без малювання — лише текст. Крок за кроком: 1) змінні → тест, 2) умови → тест, 3) вкладені умови → тест. Працюємо в Thonny: переписуй код, натискай F5, дивись на результат унизу.

Частина 1. Змінні

Змінна — це коробочка з назвою. У неї кладемо число або текст, щоб потім використати.

age = 11 читаємо: «у коробочку age поклади 11». Знак = тут не «дорівнює», а «поклади».

print(...) — виведи на екран.

Текст пишемо в лапках: "Оля". Числа — без лапок: 11.

age = age + 1 — візьми те, що в коробочці, додай 1 і поклади назад.

name = "Оля"
age = 11
print("Привіт,", name)
print("Тобі", age, "років")
age = age + 1
print("Через рік буде", age)

Має вийти:

Привіт, Оля
Тобі 11 років
Через рік буде 12

Частина 2. Умови: if і else

Умова — це питання, на яке відповідь «так» або «ні».

if — «якщо». Якщо умова правдива, виконується те, що під нею з відступом.
else — «інакше»: виконується, коли умова неправдива.

ЗнакЩо означає
> / <більше / менше
>= / <=більше або дорівнює / менше або дорівнює
==дорівнює? (два знаки — це перевірка)

Після if і else — двокрапка. Рядок під ними — з відступом 4 пробіли.

temp = 25
if temp > 20:
    print("Тепло: футболка")
else:
    print("Холодно: куртка")

Має вийти:

Тепло: футболка

Завдання 3. temp = 25 → temp = 10. Що вийде? А якщо temp = 20? Подумай: 20 більше за 20?

Завдання 4. Тепер число вводить людина. input питає, а int(...) перетворює відповідь на число:

age = int(input("Скільки тобі років? "))
if age >= 12:
    print("Можна дивитись фільм 12+")
else:
    print("Ще рано")

Частина 3. Вкладені умови

Вкладена умова — це if усередині іншого if. Друге питання ставимо, лише коли на перше відповіли «так».

Як у житті: якщо сьогодні вихідний — тоді дивлюсь у вікно: якщо сонце, йду гуляти, інакше граю вдома. Якщо не вихідний — іду до школи.

Відступи: перший if — без відступу, вкладений — 4 пробіли, print під ним — 8.

day = 6
weather = "дощ"
if day >= 6:
    if weather == "сонце":
        print("Йду гуляти")
    else:
        print("Граю вдома")
else:
    print("Йду до школи")

Має вийти:

Граю вдома

Завдання 5. Змінюй і вгадуй, що виведе: weather = "дощ" → weather = "сонце"; потім day = 6 → day = 3. Чому при day = 3 погода вже не важлива?

Завдання 6. Оцінка: спершу перевіряємо, чи вона 4 і вище, а потім — чи 10 і вище.

mark = int(input("Оцінка: "))
if mark >= 4:
    if mark >= 10:
        print("Високий рівень!")
    else:
        print("Добре, але можна краще")
else:
    print("Треба підтягнути")

Запусти тричі: 11, 7, 3.

Оцінка: 11
Високий рівень!
Оцінка: 7
Добре, але можна краще
Оцінка: 3
Треба підтягнути

★ Для швидших. Напиши програму «Кінотеатр»: змінна age і змінна money. Якщо age >= 12: якщо money >= 100 — «Купуй квиток», інакше — «Не вистачає грошей». Інакше — «Фільм 12+, не можна».
