Документація проєкту

Коментарі в коді

Пояснення прямо в програмі. Python їх пропускає. Однорядковий: #. Документаційний (docstring): """...""".

Три правила гарного коментаря

ПравилоПоганоДобре
1. Пояснюй «навіщо», а не «що». Що робить рядок, і так видно з коду.# додаємо 1 до tries# рахуємо спроби, щоб похвалити за швидку гру
2. Коментар має бути правдою. Змінив код — зміни коментар.# знижка 5 % над total * 0.9# знижка 10 %
3. Коротко, грамотно, окремим рядком над кодом# тут шось робимо з r# після z знову йде a

І ще: найкращий коментар — зрозуміла назва. shift(text, k) не треба пояснювати, а f(a, b) — треба.

Зразок: так виглядає задокументований код

def shift(text, k):
    """Шифр Цезаря: зсуває кожну малу латинську
    літеру на k позицій.

    text — слово з малих латинських літер,
    k — на скільки позицій зсунути.
    Повертає зашифроване слово.
    """
    result = ""
    for c in text:
        # номер літери від 0 до 25;
        # % 26: після z знову йде a
        n = (ord(c) - ord("a") + k) % 26
        result = result + chr(ord("a") + n)
    return result

Docstring — рядок у потрійних лапках першим рядком функції. Його показує help(shift).

Коментар усередині пояснює навіщо % 26 — це не видно з коду одразу.

Завдання 1. Знайди погані коментарі

Прочитай код. Один коментар бреше, один просто повторює код. Відповіді — у тест, питання 1 і 2. Рахуй коментарі зверху: перший, другий…

def price(total):
    # ціна зі знижкою для кошика покупця
    # якщо total >= 1000
    if total >= 1000:
        # знижка 5 %
        return total * 0.9
    # знижка 5 %
    if total >= 500:
        return total * 0.95
    # менше 500 грн — без знижки
    return total

Перевір себе: запусти з 1200 і з 600. Яка знижка насправді?

Завдання 2. Зроби код зрозумілим

Це той самий шифр Цезаря з 12.11, але написаний «для себе». Перепиши його в Thonny і:

def f(a, b):
    r = ""
    for c in a:
        r = r + chr(ord("a") + (ord(c) - ord("a") + b) % 26)
    return r


print(f("abc", 1))
  1. Дай зрозумілі назви: f → shift, a → text, b → k, r → result.
  2. Додай docstring: що робить, що означають параметри, що повертає.
  3. Додай один коментар про % 26.
  4. Запусти: shift("abc", 1) має дати bcd. Код після змін працює так само!

Частина 2. Оформлення коду

Коментарі — половина справи. Друга половина — оформлення: однакові правила запису коду для всіх, хто його пише. Тоді будь-хто відкриває чужий код і читає його легко, як книжку.

У Python ці правила записані в документі PEP 8 — його знає кожен Python-програміст. На роботі код, оформлений не за правилами, просто не приймуть.

ЩоПравилоПриклад
Змінні й функціїsnake_case: малими літерами, слова через _tries_count, get_balance()
КласиPascalCase: кожне слово з великоїBankAccount
КонстантиВЕЛИКИМИ, слова через _, на початку програмиMAX_MARK = 12
Відступ4 пробіли під for, while, if, defThonny ставить їх сам після :
Пробілинавколо = + < >=, після комиtotal = total + mark
Рядкиодна команда — один рядок; 2 порожні рядки між функціямине if x: print(x) в одному рядку
Назви-пасткине називай змінні sum, list, max, str — це вже вбудовані функціїtotal замість sum
«Магічні числа»незрозуміле число → константа з назвоюaverage >= HIGH, а не average >= 10

Завдання 4. «Причеши» код

Програма рахує середню оцінку. Вона працює, але читати її важко. Перепиши її в Thonny за правилами з таблиці.

M=[10,12,9,7]
S=0
for i in M:S=S+i
Avg=S/4
if Avg>=10:print("Високий")
else:print("Не високий")
print(Avg)

Вивід — до і після змін має бути однаковим:

Не високий
9.5
  1. Одна команда — один рядок: тіло for, if і else — на новому рядку з відступом 4 пробіли.
  2. Назви: M → marks, S → total (не sum!), Avg → average, i → mark.
  3. Пробіли навколо =, +, >= і після ком у списку.
  4. Замість 4 — кількість оцінок: total / len(marks). Тепер код працює для будь-якої кількості оцінок.
  5. Число 10 → константа на початку: HIGH = 10
  6. Додай один коментар «навіщо» — над рядком із діленням.

★ Зміни оцінки на [12, 11, 10]. Програма має сама порахувати правильно, без інших змін. Яку частину коду ти вже не мусив чіпати і чому?
