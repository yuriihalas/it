Функції в Python · 9-Б · 05.11 · ділимо програму на частини

Функція — це шматок коду з ім'ям. Написав один раз, викликаєш скільки треба. Великий проєкт складається з багатьох маленьких функцій.

Навіщо потрібні функції

Без функції

pizza = 180 - 180 // 10
tea = 120 - 120 // 10
cake = 250 - 250 // 10

Формула написана тричі. Якщо знижка зміниться, треба міняти кожен рядок.

З функцією

def discount(price):
    return price - price // 10

pizza = discount(180)
tea = discount(120)
cake = discount(250)

Формула написана один раз. Змінити треба в одному місці.

Як написати функцію

def square(x):
    return x * x

print(square(5))
25

Написати і викликати

Написана функція сама нічого не робить. Вона спрацює, лише коли її викличуть.

У Python функцію пишемо вище того місця, де викликаємо. Інакше буде помилка:

NameError: name 'square' is not defined

print і return — різні речі

return віддає результат програмі, і з ним можна працювати далі. print лише показує на екрані.

Якщо забути return, функція поверне порожнечу, і побачиш:

None

Що робити: 5 кроків до будь-якої функції

  1. Ім'я. Що робить функція? Придумай ім'я англійською, малими літерами, слова через _.
  2. Параметри. Що їй потрібно отримати?
  3. Результат. Вона має щось повернути (return) чи лише надрукувати (print)?
  4. Тіло. Напиши код усередині, з відступом.
  5. Виклик. Виклич функцію нижче і порівняй результат із прикладом.

Розв'язуємо разом: потрійне число

Завдання: функція отримує число і повертає його, помножене на 3.

  1. Ім'я: triple.
  2. Параметр: одне число x.
  3. Результат: повертає число, тому потрібен return.
  4. Тіло: return x * 3.
  5. Виклик: print(triple(4)) має дати 12.
def triple(x):
    return x * 3

print(triple(4))
print(triple(10))
12
30

Завдання

Працюємо в Thonny. Кожне завдання — окремий файл: task1.py, task2.py … Нижнього коду не змінюй: напиши функцію над ним. Готове покажи вчителю запуском.

1. Привітання

Напиши функцію greet, яка отримує ім'я і друкує привітання.

greet("Оля")
greet("Назар")
Привіт, Оля
Привіт, Назар
Підказка

Параметр один: name. Повертати нічого не треба, лише print("Привіт,", name).

2. Квадрат

Напиши функцію square, яка повертає квадрат числа.

print(square(5))
print(square(12))
25
144
Підказка

Подивись на приклад угорі. Без return виведе None.

3. Більше з двох

Напиши функцію bigger, яка отримує два числа і повертає більше.

print(bigger(3, 8))
print(bigger(10, 2))
8
10
Підказка

Параметри: a, b. Усередині if a > b:, далі return a. Інакше повертаємо b.

4. Парне число

Напиши функцію is_even, яка повертає True для парного числа.

print(is_even(6))
print(is_even(7))
True
False
Підказка

Парне число ділиться на 2 без остачі: n % 2 == 0. Цей вираз уже дає True або False, тому його можна одразу поставити після return.

Збери разом: чек у кафе

Маленький проєкт із трьох функцій. Кожна робить одну справу, а print_check викликає дві інші.

  1. total(price, count) — повертає ціну, помножену на кількість.
  2. discount(amount) — якщо сума від 100, повертає її зі знижкою 10%, інакше без знижки.
  3. print_check(item, price, count) — друкує два рядки чека.
print_check("Піца", 60, 3)
print_check("Чай", 15, 2)

Має вивести:

Піца x 3 = 180 грн
До сплати: 162 грн
Чай x 2 = 30 грн
До сплати: 30 грн
Підказка

Знижка 10%: amount - amount // 10.

Рядок чека: print(item, "x", count, "=", amount, "грн").

Остання задача: твоя функція

Кожен вигадує і пише свою функцію. Можна шукати в інтернеті, але ти маєш пояснити кожен рядок свого коду.

Умови

  1. Своя ідея, не така, як у сусіда.
  2. Функція отримує хоча б один параметр і повертає результат.
  3. Виклич її двічі з різними значеннями.
  4. Покажи запуск учителю і поясни кожен рядок.

Якщо нема ідеї

  • is_leap_year(2024) — чи рік високосний
  • to_fahrenheit(20) — градуси Цельсія у Фаренгейта
  • count_vowels("олімпіада") — скільки голосних
  • is_palindrome("радар") — чи слово паліндром
  • biggest([3, 9, 2]) — найбільше число в списку
