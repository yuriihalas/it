Розв'язуємо рівняння програмою: комп'ютер сам перебирає x або звужує проміжок, поки не знайде корінь. Працюємо в Thonny, файл rivniannia.py. Переписуй код частинами і запускай після кожного кроку. За урок — 12 балів.

Крок 1: перебір для 3x + 7 = 25 3 бали

for x in range(-20, 21):
    if 3 * x + 7 == 25:
        print("Корінь:", x)

Має вивести:

Корінь: 6

range(-20, 21) — числа від −20 до 20. Для кожного x програма перевіряє, чи ліва частина дорівнює 25. Знак порівняння — два знаки ==.

Крок 2: квадратне рівняння x² − 5x + 6 = 0 3 бали

for x in range(-10, 11):
    if x * x - 5 * x + 6 == 0:
        print("x =", x)

import math
a = 1
b = -5
c = 6
D = b * b - 4 * a * c
print("D =", D)
if D > 0:
    x1 = (-b + math.sqrt(D)) / (2 * a)
    x2 = (-b - math.sqrt(D)) / (2 * a)
    print("Два корені:", x1, x2)
elif D == 0:
    print("Один корінь:", -b / (2 * a))
else:
    print("Коренів немає")

Має вивести:

x = 2
x = 3
D = 1
Два корені: 3.0 2.0

Спочатку перебір знайшов обидва корені. Потім — те саме через дискримінант D = b² − 4ac, як на алгебрі. math.sqrt — квадратний корінь.

Крок 3: корінь, якого перебір не знайде 3 бали

Рівняння x³ + x − 5 = 0. Корінь не ціле число, тому range його пропустить. Беремо проміжок [0; 5] і щоразу ділимо його навпіл, залишаючи ту половину, де функція змінює знак. Так працює «підбір параметра» в таблицях.

def f(x):
    return x ** 3 + x - 5

left = 0
right = 5
for i in range(30):
    mid = (left + right) / 2
    if f(left) * f(mid) <= 0:
        right = mid
    else:
        left = mid
print("x ≈", round(mid, 4))
print("Перевірка:", round(f(mid), 4))

Має вивести:

x ≈ 1.516
Перевірка: 0.0

Крок 4: задача з життя 1 бал

Оля має 900 грн і щомісяця відкладає 450 грн. Навушники коштують 3600 грн. Через скільки місяців вона назбирає?

money = 900
months = 0
while money < 3600:
    money = money + 450
    months = months + 1
print("Місяців:", months)

Має вивести:

Місяців: 6

while повторює, поки умова правдива. Відповідь впиши в тест, питання 5.
