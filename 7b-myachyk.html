М'ячик у коробці · перепиши точно як тут і запусти F5

Частина 1 · вікно і м'ячик

import turtle
import time

screen = turtle.Screen()
screen.setup(800, 600)
screen.bgcolor("black")
screen.tracer(0)

ball = turtle.Turtle()
ball.shape("circle")
ball.color("red")
ball.penup()

Частина 2 · швидкість і рух

dx = 5
dy = 3

while True:
    x = ball.xcor() + dx
    y = ball.ycor() + dy
    if x > 380 or x < -380:
        dx = -dx
    if y > 280 or y < -280:
        dy = -dy
    ball.goto(x, y)
    screen.update()
    time.sleep(0.02)

Після while та if — двокрапка. Відступ — 4 пробіли або Tab. True — з великої. 0.02 — з крапкою.

Обов'язково: м'ячик літає і відбивається від стін.
Потім: зміни 1–2 числа: dx = 15, dy = 0, ball.color("yellow")
