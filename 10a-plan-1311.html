Відповіді

Завдання 4:

best = 0
best_p = 0
for p in range(0, 21):
    money = p * (100 - 5 * p)
    if money > best:
        best = money
        best_p = p
print("Найкраща ціна:", best_p, "виручка:", best)

Виведе: Найкраща ціна: 10 виручка: 500

★: два цикли x, y від 0 до 20, умова x + 2 * y == 20, лічильник — 11 розв'язків.

Типові помилки

  • Внутрішній for без відступу — цикл не вкладений.
  • = замість == у if.
  • best = 0 всередині циклу — максимум «забувається».
  • range(1, 19) замість range(1, 20) — пропускає ширину 19; на відповідь не впливає, але таблиця коротша.
